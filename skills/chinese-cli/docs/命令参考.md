# 命令参考

## 核心命令

### `/help`
显示帮助信息

**用法:**
```
/help
```

### `/config`
打开配置菜单

**用法:**
```
/config
```

### `/skills`
列出所有可用技能

**用法:**
```
/skills
```

### `/resume`
恢复之前的会话

**用法:**
```
/resume [会话ID]
```

### `/model`
选择或查看当前使用的模型

**用法:**
```
/model
```

### `/effort`
设置努力级别

**用法:**
```
/effort [low|medium|high|max]
```

### `/clear`
清除当前会话上下文

**用法:**
```
/clear
```

### `/exit`
退出Claude Code

**用法:**
```
/exit
```

## 插件管理

### `/plugin`
管理插件

**用法:**
```
/plugin [list|install|uninstall|enable|disable]
```

## 认证

### `/auth`
管理认证

**用法:**
```
/auth [login|logout|status]
```
