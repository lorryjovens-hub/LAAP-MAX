# 配置说明

## 语言设置

在 `~/.claude/settings.json` 中设置语言：

```json
{
  "language": "chinese"
}
```

支持的语言值：
- `chinese` - 中文
- `japanese` - 日语
- `english` - 英语
- `spanish` - 西班牙语
- `french` - 法语
- `german` - 德语

## 常用配置项

```json
{
  "autoDreamEnabled": true,
  "autoMemoryEnabled": true,
  "effortLevel": "medium",
  "language": "chinese"
}
```

## 配置位置

- 全局配置: `~/.claude/settings.json`
- 项目配置: `.claude/settings.json`
- 本地配置: `~/.claude/settings.local.json`
