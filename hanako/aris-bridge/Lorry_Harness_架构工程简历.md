专注于 **AGI Harness 工程**——让 LLM 不只是"会生成文本的模型"，而是一个**受控、可预测、可审计、能自我进化**的智能体系统：

## 🛠️ Harness 工程核心技能

### 管线架构
- **HEP（Harness Engineering Protocol）**：组件注册 → 模板装配 → 零 Token 生成（组件化管线设计）
- **认知管线分层（L0-L4）**：问候/知识检索/深层推理/代码理解/LLM 兜底的分层路由
- **PGTP（Pipeline-Gated Token Passing）**：生成-门控-交付三段式管线，置信度分级（pass/flag/rewrite/block）
- **工具注册与调用编排**：将验算/预测/学习/策略包装为原生 Agent 工具

### 状态空间与贝叶斯
- **粒子滤波（Particle Filter）**：500 粒子序贯重要性采样 + 系统重采样，非线性状态估计
- **MCMC 参数学习**：Metropolis-Hastings 随机游走，4 链 + R-hat 收敛诊断
- **不确定性分解**：认知不确定性（模型无知）/ 偶然不确定性（数据噪声）分离
- **状态空间模型**：需求-情感 13 维隐藏状态，预测步/更新步标准贝叶斯滤波

### 可靠性工程
- **幻觉防御四层管线**：世界模型校验 → 因果一致性 → Ψ-Net 共识 → PGTP 门控
- **信息质量过滤**：源可信度评分（学术/官方/维基/新闻/论坛分级）+ 多源交叉验证 + 世界模型冲突硬阻断
- **主动学习闭环**：认知不确定性检测 → 自动搜索 → 质量过滤 → 知识灌入 → 不确定性反馈下降

### 工程实践
- **Python 生产级服务**：HTTP 侧车（30+ API 端点）、进程生命周期管理、健康检查自动重启
- **原生插件集成**：Python 引擎封装为宿主平台原生插件（工具注册 + 上下文注入 + 配置化）
- **持久化与恢复**：状态落盘、跨会话恢复、CRDT 记忆同步

## 🧠 LAAP 架构工程核心技能

### 认知架构设计
- **PSI 需求系统**：五需求（competence/autonomy/relatedness/certainty/growth）数值引擎，衰减-满足微分模型，注意力焦点映射
- **8 维情感引擎**：需求满足率微分 → 情感向量，情感转移矩阵学习
- **意识工程**：ConsciousnessBus 事件总线、SurprisePredictor（预测误差）、TemporalBinding（3 秒延伸现在）、PresentSelfModel（当下自我）、NarrativeLink（叙事自我 L4）

### 知识系统
- **统一世界模型**：物理/抽象/社会/时间/反事实五维实体管理，关系图谱
- **统一因果引擎**：do-演算、PC 因果发现、反事实推演、因果一致性校验
- **涌现型自我模型**：能力追踪（proficiency levels）、置信度校准（predicted vs actual）、身份叙事

### 数学基础
- **自由能原理（FEP）**：变分自由能（VFE）感知推断、期望自由能（EFE）行动选择、偏好先验嵌入
- **哥德尔不完备性工程化**：宪法层外部锚定、负向安全范式、约束异化防护
- **贝叶斯定理全链路**：先验 → 观测 → 后验 → 预测分布

### 系统集成
- **跨平台记忆网络**：CRDT（Lamport 时钟 + 因果父链），微信/飞书/桌面三端同步，逻辑日约定
- **LLM 无关架构**：人格参数存于需求系统，换模型不变性格
- **蜂群协作**：Ψ-Net 共识网络、多 Agent 心智理论（k 阶 ToM）
