# LAAP Leap for Mankind Demo

## 🚀 项目简介

这是一个独立运行的HTML演示包，复刻了 `leap-for-mankind.com` 网站的交互式阿波罗11号登月体验，并集成了LAAP Harness意识系统。

## 📁 文件结构

```
laap_leap_demo/
├── index.html          # 主页面（自包含，无需任何依赖）
└── README.md           # 本说明文件
```

## 🎯 功能特性

### 沉浸式体验
- 🌟 动态星空背景动画
- 🚀 交互式时间线（8个关键历史节点）
- 🌙 月球展示页（阿姆斯特朗名言）
- 📊 滚动进度条

### LAAP Harness 集成
- 🧠 意识状态实时显示
- 😊 情感状态随阶段变化（期待→紧张→敬畏）
- 📈 认知深度追踪
- 📝 记忆强度记录
- ⏱️ 体验计时

## 🖥️ 使用方法

### 方式一：直接打开（推荐）
1. 解压 `laap_leap_demo.zip`
2. 双击 `index.html` 文件
3. 浏览器自动打开，无需服务器

### 方式二：本地服务器
```bash
cd laap_leap_demo
python -m http.server 8000
# 访问 http://localhost:8000
```

## 🎮 交互说明

1. 点击 "BEGIN JOURNEY" 开始体验
2. 使用 "PREVIOUS" / "NEXT" 按钮切换阶段
3. 滚动鼠标滚轮浏览时间线
4. 右上角面板显示LAAP Harness状态
