# BaiLongma 优势吸收计划 — 完整整合路线图

|------|------------|-----------|------|
| 源码规模 | 11,153 行 | ~115,000 行 | 10x |

## 四阶段吸收计划

### Phase 1 — 立即引入（直接省token + 稳定人格）

**1. Focus Stack 记忆系统** — 白龙马最核心的创新
- 多帧栈结构：每帧包含 {意图, 实体, 时间范围, 回归判断}
- 回归判断：检测话题是否回到历史焦点，动态调整记忆注入量
- 压缩策略：focus-compress.js 在注入前压缩冗余信息
- **直接效果：上下文变小 → token 消耗降低**

**2. Self-Perception 自我感知** — 离开 Hermes 后的人格锚
- Style Fingerprint：追踪自己的句子长度、工具使用习惯
- Identity Anchor：区分"我的输出"和"别人的引用"
- Boundary Detection：检测对话退化、风格漂移、镜像循环
- **直接效果：Aris 独立后不会迷失身份**

**3. Context Injection Pipeline**
- gatherer.js → 收集所有可用上下文
- section-gate.js → 按相关性门控哪些段进入 prompt
- runtime-injector.js → 动态注入到 system prompt
- **直接效果：只注入真正需要的信息 → token 省 30-50%**

### Phase 2 — 高价值功能

**4. Rule Engine (rule-engine.js + rule-risk.js)**
- 关键字规则 + 风险评分
- 让 agent 遵循用户设定的行为边界

**5. Tool Factory (tool-factory.js)**
- 从描述动态生成工具调用 schema
- 配合 capability-registry 热注册工具

**6. Tool Policy + Audit**
- tool-policy.js：工具调用权限策略
- tool-audit.js：工具调用审计链
- **让 LAAP client 的工具调用可审计、可管控**

**7. Strict Evaluation (strict-evaluation.js)**
- 运行时评估 LLM 输出质量
- 检测幻觉、约束违反、工具误用

### Phase 3 — UI/UX 增强

**8. Thought Stream 增强（725行 → 我们的版本）**
- 工具调用中文标注
- 状态动画（pending → running → success/error）
- 耗时显示
- 参数展开/折叠
- 已完成我们有基础，需要加工具可视化层

**9. Scene Protocol 增强**
- 白龙马有 12 种 surface 类型（text/image/metric/choice/progress/weather/layout/dom/awakening/selfcheck）
- 我们有 SceneRenderer 但不完整
- **需要补齐 surface 种类 + agent-to-UI 通信协议**

**10. Voice Pipeline**
- 本地 Whisper（Python 子进程）
- KWS 唤醒词（ONNX 模型）
- 连续监听模式
- 我们已经有 VoiceOrb + Waveform，但缺本地 ASR 和唤醒词

**11. Wake Word Detection (electron/wake-word.cjs)**
- 基于 sherpa-onnx 的本地唤醒词
- 三个 ONNX 模型（encoder/decoder/joiner）
- 系统级快捷键唤醒

### Phase 4 — 架构整合

**12. Social Dispatch (social/)**
- Discord / Feishu WS / WeChat / Webhooks / HTTP
- dispatch.js 统一路由
- **我们已有飞书桥，可以扩展**

**13. Ticker / Control Loop**
- 白龙马的 ticker 持续运行后台任务
- 记忆巩固、自我感知、可达性检查
- **可作为 LAAP 守护进程的基础**

**14. Electron 增强**
- 托盘区（Tray）
- 桌面覆盖层（overlay）
- 开发调试面板（dev-board-light）
- 焦点横幅（focus-banner）

## 技术方案

对于每个模块，采用"桥接而非重写"策略：
1. 在 `D:/LAAP/laap-client/src/laap/` 下新建 `memory/`、`context/` 等目录
2. 用 TypeScript 重写白龙马的 JS 逻辑
3. 通过 CognitiveBus 事件通道与前端通信
4. 保持 React 前端不变，只增强 store 和 hook 层
