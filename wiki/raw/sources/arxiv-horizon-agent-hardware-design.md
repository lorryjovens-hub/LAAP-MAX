## Summary

Self-evolving agent framework that treats hardware design as repository-level code evolution. A hands-free agent loop iterates on hardware description code using a Markdown harness with domain knowledge, evaluator, and git/runtime policy. Self-evolving pattern similar to LAAP's RSI engine.
