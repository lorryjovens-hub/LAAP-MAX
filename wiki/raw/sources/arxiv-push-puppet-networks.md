## Summary

Novel Bayesian algorithm for structured pruning of LLMs. Learns a hierarchical function to optimally determine which network layers to keep for a given target size. Adds small number of gating parameters via hierarchical penalty function. Directly relevant to LAAP's efficiency optimization.
