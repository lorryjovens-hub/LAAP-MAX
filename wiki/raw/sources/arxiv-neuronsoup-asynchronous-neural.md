# NeuronSoup: Evolving Asynchronous, Shared-Neuron Temporal Graphs without Backpropagation

**Authors**: Subodh Kalia
**Published**: 2026-07-16
**Categories**: cs.NE, cs.LG

## Abstract

We present NeuronSoup, a neural computation architecture that replaces synchronous layer-by-layer processing with asynchronous, delay-mediated signal propagation through a pool of shared neurons. Each path in the network routes a continuous-valued signal from one input neuron to one output neuron through a shared pool of intermediate neurons.

## LAAP Relevance

NeuronSoup's asynchronous, shared-neuron architecture is conceptually similar to LAAP's cognitive architecture goals — replacing rigid layer-by-layer processing with more flexible, persistent signal propagation paths. The backprop-free training is also relevant to the evolution of our hybrid quantum engine.

## Key Insights

1. Asynchronous processing instead of synchronous layer-by-layer
2. Shared neuron pool enables flexible routing
3. Delay-mediated signal propagation for temporal processing
4. No backpropagation required for training
