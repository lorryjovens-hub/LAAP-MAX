# Hybrid Verified Decoding: Learning to Allocate Verification in Speculative Decoding

**arXiv ID:** 2606.01019  
**Published:** 2026-06  
**Authors:** Xin Su, Dawid Majchrowski, Fangyuan Yu, et al.  
**URL:** https://arxiv.org/abs/2606.01019

## Abstract

Large Language Model inference can be accelerated by speculative decoding, where multiple candidate tokens are generated by a draft model and then verified by the target model. However, the standard verification process is wasteful — it treats all candidate tokens uniformly regardless of how likely they are to be accepted. Hybrid Verified Decoding (HVD) introduces a learned verification allocator that predicts which candidate tokens need full target-model verification and which can be verified using a cheaper proxy. By allocating verification budget adaptively, HVD reduces verification overhead by 40% while maintaining output quality, achieving end-to-end speedups of 2-2.5x over standard autoregressive decoding.
