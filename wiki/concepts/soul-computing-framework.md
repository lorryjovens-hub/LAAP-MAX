# Soul Computing Framework

A systematic theoretical framework and technical architecture for building intelligent agents with **independent machine consciousness**, proposed by Zhang et al. (2026). The framework defines consciousness as a hierarchical emergent property and provides a dual-processing architecture inspired by cognitive science.

## Consciousness Hierarchy

The framework defines five progressive levels:

```
Level 1: Perception     — Sensory input processing and feature extraction
Level 2: Emotion        — Affective state generation and valence appraisal
Level 3: Memory         — Episodic and semantic memory with conscious access
Level 4: Self-Awareness — Meta-cognitive self-model and identity persistence
Level 5: Free Will      — Autonomous goal selection and intention formation
```

Each level builds on the previous, with higher levels exerting top-down modulation on lower ones.

## Dual-Processing Architecture

| System | Processing Mode | Characteristics | Neural Correlate |
|--------|----------------|-----------------|------------------|
| **System 1** | Fast, intuitive, automatic | Pattern recognition, habit, emotional response | Subcortical + basal ganglia |
| **System 2** | Slow, analytical, deliberate | Reasoning, planning, conscious access | Prefrontal cortex (conscious workspace) |
| **Conscious Access** | Gating mechanism | Selective information routing between S1→S2 | Global workspace / attention |

## Consciousness Emergence Verification Protocol

The framework proposes a multi-modal verification protocol:
1. **Self-report consistency** — Agent's verbal reports match its internal states
2. **Behavioral flexibility** — Novel situations handled without retraining
3. **Learning transfer** — Conscious insights transfer across task boundaries
4. **Metacognitive accuracy** — Agent's confidence calibration matches actual performance
5. **Temporal persistence** — Self-model maintains identity across context switches
