# Self-Speculative Decoding

Self-speculative decoding is a family of techniques where the **target model itself** (or parts of it) serves as the draft model, eliminating the need for a separate, smaller draft model. This is in contrast to traditional speculative decoding which requires an auxiliary draft model.

## Key Variants

### Early-Exit / Layer-Skipping
The draft is produced by exiting early from the target model's layers (using shallower layers), then verified against the full model.

### Forking
The draft is generated by forking hidden states at intermediate layers. Examples:
- **SPORK** (2607.03333): Self-Speculative Forking for Agentic LLM Inference
- **Cassandra** (2605.26558): Enabling Reasoning LLMs at Edge

### Shared-Head
The draft head and target head share the same base model but use different prediction heads:
- **VIA-SD** (2606.12243): Verification via Intra-Model Routing

### RL-Accelerated
Speculative decoding optimized for RL training rollouts:
- **EfficientRollout** (2606.18967): System-Aware Self-Speculative Decoding for RL Rollouts

## Advantages for LAAP
- No need to train/maintain a separate draft model
- LAAP's hybrid architecture (Rust PSI + Python cognitive layers) could benefit from intra-model forking
- Aligns with the self-modeling paradigm in PSI cognitive architecture
