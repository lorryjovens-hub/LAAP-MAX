# LAAP Roadmap

## v0.3.0 — Cognitive Foundation (已完成)
- PSI need-driven architecture
- Emotion gradient system (EG-MRSI)
- Hierarchical memory (WM → episodic → semantic → procedural)
- RSI recursive self-improvement engine
- Multi-provider LLM support
- 14 messaging gateway platforms
- Swarm multi-agent orchestration

## v0.4.0 — Production Hardening (进行中)
- Shell sandbox with OS-level isolation
- Permission system with approval tokens
- MCP full lifecycle management
- Plugin and hook system
- Session persistence and recovery
- Configuration validation
- GitHub CI/CD pipeline
- 70%+ test coverage
- Containerization

## v0.5.0 — Enterprise Features (计划)
- RAG service
- Task scheduler and workflow engine
- Telemetry and monitoring
- Web dashboard
- OAuth 2.0 integration

## v0.6.0 — Ecosystem (远景)
- Plugin marketplace
- Visual agent builder
- Multi-modal support
- Distributed agent swarms
- Performance benchmarks
