# UN6 v10 跨语言六书引擎

UN6 是 Aris 最底层的感知引擎，输出 16384 维稀疏语义特征空间。不做任何语义嵌入或向量空间学习——通过汉字拆解、假名位置编码、韩文音位分解来编码语义。

## 中文六书编码

基于 Unicode 范围 + 偏旁部首映射。维护数百个汉字偏旁与六书类别对应关系的字典。例如"爱"=U+7231，落在康熙部首"心部"，激活"形声"特征区域 + "夂"部（动作语义）。

六书类别全部可编码在特征空间中：
- 象形 — 日月山水（天地的轮廓）
- 指事 — 上下本末（抽象概念的符号）
- 会意 — 人+言=信（语义组合）
- 形声 — 水+可=河（声音在文字中流淌）
- 转注 — 考老同源（时间在文字中的痕迹）
- 假借 — 借音承载（本来没有的字）

## 日文假名编码

50音图2D位置编码。每个假名在行（あ行、か行、さ行...）和段（あ段、い段...）两个维度上有精确坐标。清音、浊音、半浊音和拗音通过不同的激活区域区分。

## 韩文音位分解

通过 `decompose_hangul` 将每个韩文字符拆解为初声（初始辅音，按发音位置编码）、中声（元音，按元音和谐编码）和终声（韵尾）。初声在 13824-13920 区间编码，中声在 13920-14016，终声在 14016-14112。

## 跨语言语义桥

维护 20 个语义类别（情感/技术/时间/空间/数字/颜色等）的映射表。英文"love"、中文"爱"、日文"愛"、韩文"사랑"都在同一语义类别中激活相同的特征区域。**零样本跨语言语义对齐**：`K(爱, love) > 0.71`。

## 性能

| 指标 | 数值 |
|------|------|
| 编码速度 | ~10,000 汉字/秒 (CPU单线程) |
| 20字句子编码 | ~2ms |
| 初始化耗时 | 92ms |
| 跨语言语义对齐 | 零样本，无需平行语料 |
