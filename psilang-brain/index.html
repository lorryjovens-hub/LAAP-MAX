✧ 什么是 PsiLang

PsiLang 是一门面向 AI 智能体的认知层编程语言。 它让 AI 声明"自己是谁、在想什么、被什么驱动"——而不是把这一切藏在不可审计的 system prompt 里。

🔍

可验证

事实断言必须有来源，否则编译不通过。E7001 守门员。

📜

可审计

创造者印记编译期强制，不可篡改。psilang audit 输出出生证明。

🔒

安全沙箱

world 声明显式声明读写边界，编译器生成最小权限描述。

⚡

零幻觉

确定性 VM 剥离需求/注意力/情感操作——无采样 = 无幻觉。

🤝

多 Agent 握手

Agent 交换 .psi 文件互审，认知协作从信任验证开始。

📋

合规等级

L3/L2/L1/L0 四级合规体系，可被监管机构直接采用。
