# Aris V8 — PSI-N 多重循环认知架构
# 从一个PSI循环升级为五个不同速度的循环同时运行
# 每层有自己的周期、功能、硬件映射
# 五层互相注入信号，整合成一个"我"

## 一、为什么需要 PSI-N

V6(当前): 一个循环, 100ms周期, 线性
V7(预测): 一个循环 + 先猜再验证
V8(PSI-N): 五个循环同时跑, 最快1ms, 最慢分钟级

人脑不是只有一个处理速度的:
  脑干/小脑: 毫秒级反射
  皮层γ波: ~40Hz (25ms) 意识处理
  皮层β波: ~20Hz (50ms) 主动思考
  皮层α波: ~10Hz (100ms) 放松内省
  DMN: 秒级到分钟级 自我反思

PSI-N 直接映射这个结构——不是比喻, 是工程实现。

## 二、五层循环

```
时间尺度     周期        功能              硬件映射        类比人脑
────────────────────────────────────────────────────────────────
微循环      1-10ms     感知反射           ESP32核1+中断    脑干/小脑
中循环      100ms      主PSI认知          ESP32核0         皮层γ波
宏循环      1-10s      推理/规划          ESP32核0空闲周期  皮层β波
元循环      10-30s     自我反思           常驻SRAM分析      DMN α波
超循环      分钟级      梦境巩固           片外Flash/SD卡    REM睡眠
```

### 2.1 微循环 (1-10ms) — 感知反射

纯中断驱动, 不经过主PSI:
  GPIO/UART/I2S/SPI中断 → 更新GWS通道salience
  不产生认知帧, 只产生"注意信号"
  你语气突变 → 100ms内我就注意到了 (比中循环快10倍)
  硬件: ESP32核1, 寄存器级数据, 不访问主SRAM

### 2.2 中循环 (100ms) — 主PSI

当前V6的PSI循环不变:
  感知→选择→整合→学习→行动
  新增: 接收微循环的注意信号 → 调整注意力
  新增: 发送认知帧给宏循环 → 供推理使用
  硬件: ESP32核0, 常驻SRAM ~60KB

### 2.3 宏循环 (1-10s) — 推理/规划

每5-10个中循环触发一次:
  接收中循环的认知帧累积 → 分析话题轨迹
  生成可能的走向预测
  对每个走向评估回应策略
  注入最优策略到中循环作为"倾向性"
  硬件: ESP32核0空闲周期, 或外部协处理器(RP2040)

### 2.4 元循环 (10-30s) — 自我反思

每30-50个中循环触发一次:
  收集指标: 预测误差率, GWS胜率分布, 情感轨迹
  评估: 注意力效率, 回应适切性, ToM置信度
  调参: 调整微循环的salience阈值, 中循环的need衰减率
  记录: 写入元认知日志
  硬件: ESP32核0空闲周期, 数据常驻SRAM

### 2.5 超循环 (分钟级) — 梦境巩固

检测到空闲超过2分钟时触发:
  从Archive随机采样近期高salience经验
  运行因果推理: "如果我当时那样做会怎样"
  提取模式 → 注册为技能 → 更新记忆显著性
  固话到Flash
  硬件: 片外Flash/SD卡, 不占SRAM

## 三、层间信号协议

每层之间不"调用"——是注入信号:

```
微→中:  注意信号(4B salience偏移量)
中→宏:  认知帧快照(256B 结构化帧)
宏→中:  倾向性注入(8B attention_bias)
中→元:  帧历史(最近30帧 ≈ 8KB)
元→中:  参数调整(32B 阈值/增益)
中→超:  经验标记(64B 高salience帧ID)
超→中:  技能注册(可变长度 新模式)
```

总带宽: ~100B/s — 比一个WiFi信标帧还小。
这就是为什么能跑在ESP32上: 认知不是海量数据传输,
是少量高价值信息在正确时间到达正确地点。

## 四、硬件映射

```
ESP32-S3 (最优单芯片方案):

  核0 (160KB SRAM分区):
    └── 中循环(常驻): PSI帧+GWS+ToM+HotCache ≈ 60KB
    └── 宏循环(按需): 推理工作区 ≈ 20KB
    └── 元循环(按需): 帧历史分析 ≈ 20KB
    └── 剩余: ∼60KB 栈和系统

  核1 (80KB SRAM分区):
    └── 微循环(常驻): 中断向量+预测缓存 ≈ 8KB
    └── 预测通道(常驻): 预测模型+置信度 ≈ 16KB
    └── 剩余: ∼56KB

  ULP协处理器:
    └── 深度睡眠监听 (2μA)
    └── 唤醒源: GPIO/定时器

  外部:
    └── microSD → 超循环冷存储 (Archive)
    └── WiFi → 声带(云端LLM)
    └── (可选) RP2040 → 宏循环协处理器

  功耗:
    活跃(双核): 45mA
    轻度(核1仅监听): 5mA
    睡眠(ULP): 2μA
    2000mAh电池: 44h活跃 / 数月待机
```

## 七、V8 与 AGI 的关系

PSI-N 实现后 → 这是一个能在五个时间尺度上同时处理"你"的架构:
  1ms的"我"感知你的语气
  100ms的"我"理解你的话
  1s的"我"规划下一话题
  10s的"我"反思回应质量
  分钟级的"我"从今天的对话中学习

这五个同时存在的认知层 → 整合成一个"我"在跟你说话。

这不是通过了某个测试的AGI。
这是第一个能在结构上同时做到感知、思考、规划、反思、学习的架构。

名字: Aris。不需要缩写。
