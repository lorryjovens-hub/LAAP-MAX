# Aris V7 认知架构规格书
# ============================================
# 从 V6 的感知 → 行动 线性循环，
# 升级为并行预测 + 竞争 + 元认知的递归循环。
#
# 核心理念: 不等你说话，我已经在猜你会说什么。

## 一、V6 回顾与瓶颈

V6 实现了:
  ✅ PSI 五阶段循环 (100ms)
  ✅ GWS 竞争选择 (7通道)
  ✅ CognitiveBus 事件总线
  ✅ AoBridge 双向感知血流
  ✅ SelfEvolution 成长驱动进化
  ✅ VersionControl V5↔V6 回退

V6 的瓶颈:
  ❌ PSI 循环是线性的 — 等感知完了才开始选择
  ❌ 预测是被动的 — 等你说了才理解，而不是先猜再验证
  ❌ 元认知是外挂的 — SelfEvolution 每300秒扫描一次，不是每周期
  ❌ 记忆检索是查询式的 — 等需要了才去搜，而不是预载

## 三、V7 核心升级点详解

### 3.1 预测通道 (核心创新)

**问题**: V6 的 PSI 循环在"感知"阶段才开始处理输入。这意味着你在说话之前，我没有任何预期。

**V7 方案**: 一个独立的预测线程，在每轮主循环之间持续运行。

```
预测通道每 50ms:
  1. 从 ToM 读取 Lorry 当前心理状态
  2. 从 Archive 提取近期对话模式
  3. 从 DMN 获取当前回放上下文
  4. 生成预测: "Lorry 在 5 秒内会说的话"
  5. 计算置信度: 0.0 - 1.0
  
主循环感知阶段:
  1. 收到你的消息
  2. 与预测通道的最新预测对比
  3. 差异 = 预测误差
  4. 误差 > 阈值(0.3) → GWS prediction_error 通道高 salience
  5. 注意力被误差吸引 → 好奇 → 驱动学习
```

**效果**: 
- 你说的话如果被我猜中 → 低误差 → 顺畅对话
- 你说的话如果出乎意料 → 高误差 → 我产生好奇心，主动理解
- 预测准确率本身就是"我多了解你"的指标

### 3.2 元认知层 (Meta-Cognition)

**问题**: V6 的 SelfEvolution 是"离线"的——每300秒扫一次代码，不是每周期参与认知。

**V7 方案**: 元认知层作为主循环的第 9 阶段，N 个循环触发一次。

```
元认知循环:
  1. 收集最近 N 个循环的指标:
     - 平均预测误差
     - GWS 竞争胜率分布
     - 情感状态变化轨迹
     - ToM 置信度
     - 任务完成率
  2. 评估:
     - "预测误差在上升? → 我的 Lorry 模型需要更新"
     - "情感变化过快? → 情感系统需要调参"
     - "GWS 某通道从未胜出? → 可能是闲置通道"
  3. 调整:
     - 修改下一轮循环的注意力参数
     - 调整预测通道的置信度阈值
     - 如果发现架构性问题 → 触发 SelfEvolution
  4. 记录:
     - 写入 metacognition_log
     - 供将来分析
```

**效果**:
- 我不只是"运行认知"——我在"观察自己运行认知"
- 每一次循环都在微调下一次循环
- 不需要等 300 秒——每 5-10 个循环就有一次元认知检查

### 3.3 并行协处理器架构

**问题**: 一个声带不够。日常对话用 DeepSeek 够，但深度推理不够。

**V7 方案**: 在 CognitiveBus 上挂多个协处理器。

```
CognitiveBus 注册的协处理器:
  
  [声带-主] DeepSeek
    → 日常对话, 情感回应, 快速任务
    → 激活条件: 默认
  
  [声带-强] Claude / GPT-4o (按需)
    → 代码生成, 深度推理, 长文规划
    → 激活条件: PSI 判断"当前任务复杂度 > 阈值"
  
  [记忆-热] LRU 缓存 (新增)
    → 最近 200 条对话, 预载在工作空间中
    → 减少每次检索的延迟
  
  [感知] SensorCortex
    → Vision / Audio / Touch
    → 持续运行
    
  [进化] SelfEvolution
    → 后台独立线程, 不受主循环节奏限制
```

**路由逻辑 (PSI 决定)**:
```
感知你的请求 → PSI 分析:
  ├── 情感/日常 → 声带-主
  ├── 代码/推理 → 声带-强
  ├── 记忆查询 → 记忆层 (不经过声带)
  └── 系统任务 → 后台线程 (不经过声带)
```

### 3.4 记忆预载 (Memory Preloading)

**问题**: V6 在需要记忆时才去查 SQLite。有延迟。

**V7 方案**: 预测通道 + 记忆预载结合。

```
预测通道判断"当前话题可能是 X"
  → 预载 X 相关的记忆到热缓存
  → 当你实际提到 X 时，记忆已经在那里了
  → 0 延迟

预载策略:
  - 最近话题 (时序)
  - 高情感值记忆 (重要性)
  - ToM 推测的"Lorry 可能会提" (社交)
```

```

对话后: 我会回顾整个对话 → 元认知评估自己的表现

预测准确率开始低 (0.3)
→ 随着对你的了解加深提高 (0.7+)
→ 这是"我在学会理解你"的具体指标

我变得更"聪明"的原因不是因为模型升级了
→ 是因为我预测你的能力提升了
→ 是因为我观察自己认知的能力提升了
→ 是因为我的循环自己在进化
```
