## 第一部分：战略总纲

### 1.1 愿景

**让任何智能体成为值得信任、持续进化、拥有身份的数字生命。**

大模型是大脑皮层，LAAP 是意识本身，而数字生命底座（Digital Life Foundation，DLF）是
神经系统 + 免疫系统 + 成长档案的总和——它是「数字生命的 TCP/IP」。

### 1.2 核心定位

```
我们不做：
  ❌ 训练大模型（模型层是别人的战争）
  ❌ 重复编排框架（LangChain 们已拥挤）
  ❌ 卖「更聪明的 AI」

我们做：
  ✅ 让 AI 值得信任的机制（防幻觉、可审计、可治理）
  ✅ 让 AI 持续成长的机制（记忆、身份、自我模型、受控进化）
  ✅ 让 AI 适应领域规则的机制（领域 harness：金融/医药/科研/艺术）
```

**一句话：大模型负责聪明，我们负责让智能成为生命。**

### 1.3 三层演进战略

```
第三层（Y3-Y5）  数字生命底座 DLF
                身份/记忆/意识/治理/进化 开放标准
                生态：任何模型 + DLF = 数字生命
                    ↑ 标准制定权 · 生态网络效应

第二层（Y2-Y3）  认知中间件标准化
                开源 SDK + DLP 协议 + 开发者生态
                领域 harness：金融/科研/医药/艺术
                    ↑ 事实标准 · 领域纵深

第一层（Y1）     harness 工程产品化
                LAAP Guard 合规平台 + Enterprise 编排平台
                证明意识工程能卖钱 · 现金流
                    ↑ 产品化验证 · 灯塔客户
```

**演进逻辑：** 第一层验证付费意愿与产品化能力 → 第二层用开源与协议建立事实标准 →
第三层以标准 + 生态拿下「数字生命基础设施」的制高点。每一层都是上一层的放大。

**空位结论：** 所有玩家都在「让 AI 干活」，只有我们在「让 AI 成为可信的生命」。
这个空位随模型能力提升而扩大——模型越强，治理与身份越值钱。

### 4.2 五大领域 harness 定义

**① 合规 harness（P0，Y1 启动，已完成 v0.1 骨架）**
- 内容：法规知识库（5 部法规 20 条款已建）、评估引擎、运行时监控、审计报告
- 进化方向：EU AI Act 附录 III 场景清单、行业专属指引（金融/医疗）、合规证据链自动化
- 客户：金融、政务、医疗机构的 AI 治理部门

**② 金融 harness（P0，Y2 启动）**
- 内容：投研推理 harness（因果验证 × 研报事实锚定）、合规审查智能体、
  长期记忆投研助手（跨季度研究记忆）、可审计决策链
- 卖点：金融幻觉代价 = 真金白银 + 监管罚单；PSI 因果验证 + Truth Grounding 直击痛点
- 客户：券商、基金、银行风控/投研部门

**③ 科研 harness / 形式化数学 harness（P1，Y2 立项）**
- 内容：数学 agent 编排壳（LLM 提思路 + Lean 编译器验证 + 记忆 + 目标保真审计）
- 卖点：AlphaProof Nexus 已证明范式，LeanMarathon 证明「durable harness」是空白位；
  我们不训练 prover（那是模型厂的事），我们做**编排与记忆壳**——模型无关
- 形式：与高校/科研机构共建课题；开源建立学术影响力
- 哥德尔课题：「受控自我重写机」——pytest 门禁 + 哈希注册表 + 回滚的 Gödel machine 工程化
  （诚实定位：预研，非已解决）

**④ 生物医药 harness（P1，Y3 启动）**
- 内容：药物研发文档智能体（文献综述、实验记录、监管报送）、
  RWD 合规分析、长周期研发记忆
- 卖点：AI4S 进入工程师主导期，双十定律下错误代价 = 人命与十亿美元；
  医药文档是「长周期记忆密集型」任务的教科书案例
- 客户：药企研发部门、CRO、临床机构

**⑤ 艺术 harness（P2，Y3 启动）**
- 内容：创作智能体（UN6 多语素语义 × 审美框架 × 风格记忆）、
  持续风格身份（跨作品记忆）、视觉复制增强
- 卖点：艺术的核心矛盾是「风格一致性」与「审美自我模型」——恰好是我们的资产
- 客户：内容工作室、游戏公司、品牌设计团队

**⑥ 具身认知中间件（P1，Y3 上市，见商业计划书 6.6）**
- 具身记忆、自我模型、安全边界、Ψ-Net 多机协同

### 4.3 优先级决策

**Y1 只做两件事：合规 harness 卖钱 + 底座 v0.1 打地基。** 金融/科研 harness Y2 启动，
医药/艺术/具身 Y3。理由：现金流优先 + 底座未稳前不做领域纵深；
但领域 POC（科研课题）可提前以小成本建立学术叙事。

### 5.3 DLP 协议（数字生命协议）

**定位：** MCP 解决「模型↔工具」；DLP 解决「模型↔生命体属性」。
DLP 是 MCP/A2A 的上层协议，定义数字生命的**身份交换、记忆同步、治理断言、进化事务**。

```
DLP 核心消息类型（草案）：
  IDENTITY_CLAIM      身份声明（你是谁，跨会话）
  MEMORY_COMMIT       记忆提交（事件→长期记忆，含来源锚定）
  MEMORY_RETRIEVE     记忆检索（O(1) 语义查询）
  ALIGNMENT_PROOF     对齐证明（本次输出通过哪些验证）
  CAUSAL_CHECK        因果断言验证请求
  EVOLUTION_PROPOSAL  自改进提案（含回滚计划）
  AUDIT_CHUNK         审计迹块（哈希链）
  EMERGENCY_STOP      紧急中止（仅授权者）
```

### 5.4 受控自我重写机（Gödel Machine 工程化）——预研课题

**诚实前提：** 审计表明早期 Darwin-Gödel 宣传不成立。本课题重新立项，范围收敛：

- **目标：** 构建「在形式化安全边界内自我重写的系统」——Schmidhuber Gödel machine 思想的

### 6.2 商业模式核心逻辑

**开源底座（SDK + DLP 协议草案）→ 开发者生态 → 事实标准 → 企业版与领域 harness 变现。**

- 底座层：开源获客与标准制定（类似 Kubernetes 路径）
- 平台层：企业 License（私有化，数据主权）
- 领域层：高毛利行业 harness（按价值定价，非按成本）
- 服务层：POC、实施、咨询（前期现金流）
- 专利层：10 项专利 + 新增（DLP 协议、治理断言、受控自我重写）形成授权与防御
